# Echo the Bat — Image Prompts

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Generate each pose in its own request, in the order below, and re-use the
same chat so the style stays consistent. Ask for 1024x1024 pixels. Save each
result with the filename given, then run the padding trimmer (see the end of
this file).

**Pronouns:** Echo has no gender. Always write "Echo" or *they/them*.

## After Generating: Trim the Padding

AI image generators add a lot of transparent padding. Save all seven files in
`docs/img/mascot/`, then run this from the project root (`signal-processing/`):

```sh
for f in neutral welcome thinking tip warning encouraging celebration; do
  python "$BK_HOME/src/image-utils/trim-padding-from-image.py" docs/img/mascot/$f.png
done
```

Then open the mascot test page (`docs/learning-graph/mascot-test.md`) to confirm
every pose passes the transparency and 4 px trim checks.
